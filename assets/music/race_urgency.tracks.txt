==============================================================================
配乐 MIDI 轨道清单: race_urgency.mid
==============================================================================
文件类型      : Standard MIDI File Type 1（多轨，App 可逐轨编辑）
轨道数        : 7（含 1 条速度轨）
时间分辨率    : 480 ticks / quarter
速度          : 165.0 BPM · 4/4
总时长        : 01:33（93.1 秒 / 122880 ticks）

------------------------------------------------------------------------------
每轨乐器对照（GM 音色号 = 手机 App 里可选的标准 GM 音色编号）
------------------------------------------------------------------------------

轨道 1  「1-Strings Staccato」
    MIDI 通道    : 1（0 基通道 0）
    音色号 GM    : 48 → String Ensemble 1
    （面板 1 基编号: GM 49）
    音域         : MIDI 69~89
    音符数       : 577
    作用         : 紧张同音反复的弦乐脉冲（主推动力）

轨道 2  「2-Brass Alarm」
    MIDI 通道    : 2（0 基通道 1）
    音色号 GM    : 56 → Trumpet
    （面板 1 基编号: GM 57）
    音域         : MIDI 74~83
    音符数       : 80
    作用         : 铜管警报动机（每 4 小节半音上行，制造警报感）

轨道 3  「3-Bass Pulse」
    MIDI 通道    : 3（0 基通道 2）
    音色号 GM    : 33 → Electric Bass (finger)
    （面板 1 基编号: GM 34）
    音域         : MIDI 26~38
    音符数       : 545
    作用         : 八分音符脉冲贝斯（低音引擎，压迫感来源）

轨道 4  「4-Timpani」
    MIDI 通道    : 4（0 基通道 3）
    音色号 GM    : 47 → Timpani
    （面板 1 基编号: GM 48）
    音域         : MIDI 38~43
    音符数       : 32
    作用         : 定音鼓重击（心跳加重 / 段落落点）

轨道 5  「5-Synth Alarm」
    MIDI 通道    : 5（0 基通道 4）
    音色号 GM    : 83 → Lead 4 (chiff)
    （面板 1 基编号: GM 84）
    音域         : MIDI 86~99
    音符数       : 56
    作用         : 合成器警报（防空警笛式的三连上行）

轨道 6  「6-Drums Stopwatch」
    MIDI 通道    : 10（0 基通道 9）
    音色号 GM    : — → GM 鼓组（Drum Kit，App 里选「Standard Kit / 鼓组」）
    使用的鼓件    : Acoustic Bass Drum(35)、Acoustic Snare(38)、Crash Cymbal 1(49)、Hi Wood Block(76)、Open Triangle(81)
    音符数       : 650
    作用         : 鼓组：秒表“嗒嗒”滴答 + 军鼓/踩镲推进

------------------------------------------------------------------------------
导入 / 导出建议
------------------------------------------------------------------------------
1) 手机「音乐制作工坊」导入：选 MIDI 文件 → 6 条乐器轨会按顺序出现，
   鼓组轨需在 App 里指定为 Standard Kit（GM 鼓组通道）。
2) 保留 GM 音色号，导出时选 44.1kHz / 立体声 / OGG 或 WAV。
3) 成品放回 assets/music/race_urgency.ogg（文件名必须一致），
   游戏会自动加载；未放文件时会回退到地图原声，不会报错。
4) 循环点：曲子是 8 小节循环 + 结尾 4 小节收束，直接循环播放即可。

------------------------------------------------------------------------------
手机端「音乐制作工坊」配置要点（据该 App 公开教程与 v2.0.6x 更新日志：支持导入 MIDI + SoundFont）
------------------------------------------------------------------------------
· 导入 MIDI：首页左上角菜单 → 下滑找到「导入MIDI文件」→ 选 race_urgency.mid
· 音色：建议每条轨都用「采样乐器 / SoundFont 播放器」+ 同一个 GM SoundFont，
  这样 program change 里的 GM 编号才能 1:1 对上（本 MIDI 只用 bank 0 的 128 音色号）
· 鼓组轨（第 6 条）在 MIDI 里是第 10 通道，SF2 侧要挂 Standard Kit 预设
· 复音数：弦乐/贝斯轨 8~16 够用，鼓组 4~8 即可（太高吃 CPU 会卡）
· 导出：OGG（44.1kHz 立体声）→ 改名 race_urgency.ogg → 放 assets/music/

· 常见坑：6 条轨全挂同一个 SF2，出来全是钢琴 ——
  ① SF2 是「音色库」不是单乐器：一个文件里有几十~几百个预设(preset)，
     加载文件 ≠ 选预设；不选就全是该 SF2 的默认预设（多半是钢琴）
  ② 部分 App 导入 MIDI 时不套用 program change → 必须手动逐轨选预设
  ③ 若 SF2 不是 GM 排列（patch 顺序不对应 GM 编号），按「名字」挑别按编号挑
  ④ 鼓组轨：MIDI 第 10 通道对应 SF2 的 Standard Kit 预设（bank128/preset0）
  → 30 秒自检：导入 assets/music/gm_timbre_check.mid，6 段接力听音色对不对
