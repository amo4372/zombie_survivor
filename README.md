# 丧尸幸存者 - 黑暗尸潮

一个由 AI 持续开发维护的 Pygame 肉鸽幸存者游戏，支持 PC / Android 双平台、键控 / 触控双输入。

> 当前版本 **v2.9.22.1**（保持 2.9.x，未跳 3.0.0）。
> 本版 = **v2.9.22 的完整画面基线** + **v2.9.23 的全部数值与机制改动**，
> 不含 v2.9.23 的任何画面/渲染改动；v2.9.23 与 GPU 渲染实验版均已废弃删除。

## 本版定位

- 渲染完全沿用 v2.9.22 的纯 Pygame CPU 路径；视野机制保持「48 射线 + 1/3 分辨率遮罩 + 每 3 帧重算」，**不启用全量视野**（实测密集障碍下超过一帧预算，见 `VISION_PERF.md`），也不引入 GPU / GLES 渲染。
- 只合入数值与机制：武器独立 PvP 倍率、抗性计算系数按来源独立、湮灭射线锁血、手雷提速与对玩家生效、僵尸越障减速、独立地图编辑器与 `.zmap` 导入。
- 技能预瞄线、动态拉远视野、HUD 等与画面相关的实现与 v2.9.22 逐字一致。

## 数值与机制（相对 v2.9.22）

- AWM 对玩家一枪 **100**；`DATA_VERSION = 7`；`WEAPON_PVP_MULTS` 覆盖全部 WeaponType，每把武器一个独立 PvP 倍率，`damage_vs_player` 仍是最高权威值。
- `DamagePacket.resist_scale`：`1 − (1 − 抗性倍率) × resist_scale`。防爆肘击 0.25 / 载具撞击 0.20 / 技能 AOE 0.45，默认 1.0 吃完整抗性。
- 耐久下调：盾 500→300、观察窗 400→220；重卡 900→540、坦克 1800→1080、武直 1100→700、大运 Lv2/Lv3 1500/2200→900/1320。
- 湮灭射线改为锁血制：`220/s`、`总上限 480`、`持续 1.6s`；对敌方玩家精确保留 **1 HP** 不致死，对僵尸 / Boss 按 `0.55` 单独计算。
- 技能手雷飞行 1.1s→**0.32s**，普通投掷物 1.2s→**0.42s**；技能手雷 / EMP 现在能打到敌方玩家（独立倍率 0.75 + 独立抗性系数 0.45）。
- 所有僵尸都能跨越障碍物，穿越时移速 ×0.35；幽灵 / 幽影类仍完全不受阻。
- 地图编辑器从游戏内剥离，改为独立工具 `python3 tools/map_editor_standalone.py`（键控 + 触控），导出 `.zmap`；「导出为当前地图」后游戏零配置加载 `maps/active.zmap`，也可在 `config.json` 写 `"map_file"`。
- v2.9.22 既有机制全部保留：debuff 叠层→覆盖→免疫（不清除已有 debuff）、冰冻区域、独立 PvP 来源倍率、无畏冲锋撞 Boss/玩家退出、抗性与状态系统、格挡、AI 玩家、图鉴、回放、老虎机与抽卡。

## 运行

```
pip install -r requirements.txt
python main.py
```

Android：Pydroid3 / Termux 打开 `main.py`，自动切触控模式。

## 明确不做的事

- 网络联机：v2.9.22 起完全移除，等待重新设计后重写。
- 全量视野渲染 / GPU 渲染：实测开销与画质收益不匹配，本版一律不启用。
- 版本号不跳 3.0.0。
