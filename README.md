# 丧尸幸存者 v4.0 - 黑暗尸潮

一个类似吸血鬼幸存者的肉鸽类(Pygame)游戏。

## 剧情
某学校的班级爆发丧尸危机，你的昔日朋友龙某和向某变成了Boss级丧尸。
随着波数增加，他们会进化，甚至能与玩家交互式交流。
最终了解他们本是玩家的朋友，多结局路线等待探索。

## v4.0 更新内容

### 全新尸潮系统
- 替换传统波次，改为动态尸潮系统
- 尸潮频率和规模随时间和难度动态调整
- 屏幕上方中央显示紧迫感时间
- 无尽模式：时间先显示倒计时，5分钟后出现"SYSTEM ERROR"变成计时器（寓意没有尽头）

### 技能卡系统（替代技能树）
- 每升一级跳出3选1技能卡界面
- 技能有前置解锁条件
- 被动技能和主动技能混合出现
- 新技能权重更高

### 全新钩爪系统
- 短按直接沿当前方向发射
- 长按显示轨迹线（键控沿鼠标朝向）
- 发射后碰到敌人/道具/经验球后僵直绷紧，再慢速同步拉回
- 钩爪只消耗CD，不消耗体力
- 触控模式下完全修复

### 更多枪械（13种）
- 手枪、突击步枪、霰弹枪、狙击枪、机枪、火箭筒、火焰喷射器
- 新增：十字弩、榴弹发射器、等离子步枪、轨道炮、加特林、双管霰弹
- 每种武器有详细的弹药系统和换弹机制

### 新机制僵尸
- **爆炸僵尸**：靠近玩家后自爆
- **爬行者**：体型小速度快，有闪避几率
- **分裂者**：死后分裂成2个小僵尸
- **盾兵僵尸**：正面减伤
- **治疗僵尸**：给周围僵尸回血
- **幻影僵尸**：偶尔隐身

### 更多创新技能
- **闪烁**：瞬移到鼠标方向位置
- **黑洞**：吸引并伤害敌人
- **冰霜新星**：冻结周围敌人
- **连锁闪电**：在敌人间弹射
- **狂暴**：攻速翻倍，受到伤害增加
- **幻影打击**：召唤3个幻影分身
- **医疗舱**：部署持续回血区域
- **冲击波**：推开周围敌人

### 黑暗色调UI
- 全局配色调整为黑暗主题
- 半透明技能范围圈
- 技能释放按钮显示当前技能CD
- 触控按钮位置优化（II键移到右半屏上方中央）

## 安装
```bash
pip install -r requirements.txt
```

## 运行
```bash
python main.py
```

## 控制

### 键控模式
- WASD / 方向键 - 移动
- 鼠标 - 瞄准
- 左键 - 射击
- E - 装备防爆套装
- Q - 盾牌肘击
- F - 钩爪（短按发射，长按显示轨迹）
- 1/2/3 - 切换武器
- R - 下一个武器
- G - 使用技能
- ESC - 暂停

### 触控模式
- 左摇杆 - 移动
- 右半屏 - 瞄准
- 射击按钮 - 射击（装备防爆套装后变为肘击）
- 技能按钮 - 切换技能
- 释放按钮 - 短按释放/长按瞄准
- II按钮 - 暂停（右半屏上方中央）

## 多结局
1. **完美结局** - 使用疫苗拯救两人
2. **选择结局** - 只救龙某
3. **抉择结局** - 只救向某
4. **悲剧结局** - 有疫苗但不使用
5. **终结结局** - 没有疫苗，杀死两人
6. **放手结局** - 没有疫苗，放走两人
