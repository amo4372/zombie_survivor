# 丧尸幸存者 - 黑暗尸潮

一个类似吸血鬼幸存者的肉鸽类(Pygame)游戏，支持PC/Android双平台，键控/触控双输入。

## 剧情

某学校的班级爆发丧尸危机，你的昔日朋友龙某和向某变成了Boss级丧尸。
随着波数增加，他们会进化，甚至能与玩家交互式交流。
最终了解他们本是玩家的朋友，多结局路线等待探索。

病毒起源于城北核电站的非法生物实验，方舟生物科技公司暗中策划了一切。
神秘组织"观察者"记录着所有真相，而你——是唯一的幸存者。

## 功能特性

### 游戏模式
- **故事模式** - 5张地图，剧情收集，特殊事件，多章节继承
- **无尽模式** - 无限生存，倒计时出错后变为正向计时
- **限时模式** - 限时20分钟，尽可能存活并击败Boss

### 武器系统（20+种）
- **枪械**：手枪、突击步枪、霰弹枪、狙击枪、机枪、火箭筒、火焰喷射器、十字弩、榴弹发射器、等离子步枪、轨道炮、加特林、双管霰弹
- **近战**：拳头、砍刀、消防斧、电击棒
- **投掷物**：手雷、燃烧弹、冰冻手雷
- 每种武器有详细的弹药系统和换弹机制
- 初始武器为拳头，通过击杀和宝箱获取新武器

### 僵尸类型（30+种）
- **基础僵尸**：普通丧尸、奔跑者、胖子
- **特殊僵尸**：爆炸僵尸、爬行者、分裂者、盾兵僵尸、治疗僵尸、幻影僵尸、毒雾僵尸、电击僵尸
- **精英僵尸**：各种强化变异体
- **Boss**：龙某、向某、疫苗Boss、巨型变异体
- Boss免控（钩爪无法勾取，只能命中产生僵直），拥有智能行为

### 技能系统
- **技能卡三选一** - 每升一级跳出3选1技能卡界面
- **被动技能** - 生命强化、伤害提升、攻速提升、移速提升、暴击、生命偷取、护甲、经验加成、金币加成、磁力范围、冷却缩减
- **主动技能** - 钩爪、闪烁、黑洞、冰霜新星、连锁闪电、狂暴、幻影打击、医疗舱、冲击波、空袭、手雷
- 主动技能上限5级，满级附加特殊效果
- 技能有前置解锁条件，新技能权重更高

### 技能树系统
- 全局通用技能树，显示技能与技能之间的依赖关系
- 只显示玩家刷出过的技能（三选一出现过即解锁显示）
- 已点技能特殊显示，技能强度影响画面效果
- 支持鼠标拖拽、滚轮缩放、方向键移动
- 触控支持手指拖动

### Buff系统
- **正面Buff**：伤害提升、攻速提升、移速提升、护盾、回血、经验加成、无敌
- **负面Buff**：燃烧、流血、中毒、冰冻、减速、眩晕、虚弱
- Buff可叠加，有持续时间
- 区域Buff：燃烧区域、冰冻区域、毒雾区域

### 符文系统
- 尸潮奖励宝箱可开出符文
- 符文提供局内永久Buff
- 多种符文类型：攻击符文、防御符文、生命符文、速度符文、暴击符文

### 图鉴系统
- **怪物图鉴** - 所有僵尸和Boss的详细信息、属性、弱点
- **武器图鉴** - 所有武器的详细信息、伤害、射速、弹药
- **世界观** - 关键事件时间线、末日生存指南、神秘组织、疫苗研究、变异体分类
- 遇到僵尸或获得武器后自动解锁对应图鉴
- 支持触控滑动滚动

### 剧情资料库
- 100+条可收集文本资料
- 关键事件时间线（2027-2028重大事件）
- 末日生存指南（6大生存技能）
- 神秘组织（方舟计划/观察者/血商等）
- 疫苗研究（3种实验疫苗+解药方向）
- 变异体分类（7大类详细描述）
- 每张地图有独特的剧情文本

### 自动更新系统
- 从GitHub自动检测最新版本
- 下载进度条实时显示
- 热更新：自动备份、覆盖、重启
- 所有GitHub链接通过gh-proxy.com代理加速
- 更新失败自动回滚

### Mod系统
- 玩家可操控的Mod加载页面
- 可选择启用或禁用列表里的Mod
- 单击Mod显示详情信息
- Mod开发指南支持钩子系统
- 支持自定义武器、僵尸、技能、地图

### 光照渲染系统
- 根据画面质量（性能/均衡/质量）做取舍
- 玩家手电筒光源，营造恐怖压迫氛围
- 经验球发出幽幽蓝光
- 特殊僵尸散发幽光
- 子弹和爆炸光更加剧烈
- 障碍物阴影渲染

### 动态音乐系统
- 20首音乐（11首新版管弦乐+9首经典原版）
- 新旧音乐随机播放
- 多地图分别配乐
- 黑暗绝望风格管弦乐
- 支持MIDI+SoundFont转换

### 体力/疾跑系统
- Ctrl键疾跑，消耗体力
- 体力与防爆套装共享
- 体力条显示在屏幕底部中央，带数字
- 体力自动回复
- 疾跑时有画面效果

### 空袭技能
- 飞机黑影飞过
- 大范围持续轰炸
- 真正的超级核爆效果
- 更多Buff区域效果
- 与手雷技能差异化

### 存档加密
- 多层加密（XOR+字节反转+Base64+二次XOR）
- 兼容旧明文存档
- 独立加密/解密工具

### 其他特性
- 成就系统（50+成就）
- 记录系统（最高击杀、最长存活等）
- 暂停菜单
- 设置界面（音量、画质、控制模式等）
- 教程界面
- 屏幕震动
- 伤害数字
- 粒子特效
- 浮动文字

## 游戏机制

### 尸潮系统
- 动态尸潮，频率和规模随时间和难度动态调整
- 尸潮间隔随难度和时间调整
- 击败Boss后刷新奖励（武器箱、宝箱、符文）
- Boss和奖励随时间及难度有计算系数

### 难度系统
- 简单、普通、困难、地狱
- 影响玩家血量、伤害倍率、僵尸强度
- 成就系数随难度调整

### 升级系统
- 击杀僵尸获得经验球
- 经验球根据所含经验多少呈现不同形态
- 升级后三选一技能卡
- 技能刷新概率可配置（爆率系统）

### 宝箱/奖励
- 尸潮顺利度过后刷新对应规模的奖励
- 武器箱：开出新武器
- 宝箱：开出符文（局内永久Buff）
- 补给箱：回血、弹药、经验加成

## 多结局
1. **完美结局** - 使用疫苗拯救两人
2. **选择结局** - 只救龙某
3. **抉择结局** - 只救向某
4. **悲剧结局** - 有疫苗但不使用
5. **终结结局** - 没有疫苗，杀死两人
6. **放手结局** - 没有疫苗，放走两人

## 自动更新

### 发布新版本
```bash
# 指定版本号
python build_release.py --version 1.1.0 --changelog "修复了xxx"

# 自动递增
python build_release.py --bump patch    # 1.0.0 -> 1.0.1
python build_release.py --bump minor    # 1.0.0 -> 1.1.0
python build_release.py --bump major    # 1.0.0 -> 2.0.0
```

### GitHub发布
1. 打开 `https://github.com/amo4372/zombie_survivor`
2. Releases → Create a new release
3. Tag: `v1.1.0`，标题: `僵尸幸存者 v1.1.0`
4. 上传 `releases/zombie_survivor_v1.1.0_update.zip`
5. Publish release

游戏内「检查更新」会自动检测并热更新。
