# 丧尸幸存者 - 黑暗尸潮

一个由 AI 持续开发维护的 Pygame 肉鸽幸存者游戏，支持 PC / Android 双平台、键控 / 触控双输入。

> 当前版本 **v2.9.23**（保持 2.9.x，未跳 3.0.0）。

## 剧情

某学校的班级爆发丧尸危机，昔日的朋友龙某和向某变成了 Boss 级丧尸。随着波数增加，他们会进化，甚至能与玩家交互式交流。病毒起源于城北核电站的非法生物实验，方舟生物科技公司暗中策划了一切，神秘组织「观察者」记录着真相——而你是唯一的幸存者。

## 游戏模式

| 模式 | 说明 |
|---|---|
| 故事模式 | 5 张地图、剧情收集、章节继承，毒圈节奏按 20 分钟设计 |
| 无尽模式 | 无限生存，正向计时 |
| 限时模式 | 20 分钟生存并击败 Boss |

## 武器系统

**29 把武器**，全部通过「军械库补给」抽取获得，**没有直接购买、也没有直接升级**：

- 同一把武器可反复抽到，最多叠加到 Lv.5，满级后退出奖池；新档送 1200 金币用于抽取初始武器
- 米哈游式保底：5★ 3% / 4★ 13%，80 抽硬保底（含软保底），10 抽必出 4★，出 5★ 时 50% 为 UP、歪了下次必 UP，14 天一期轮换卡池
- 抽取演出分铺垫 / 闪光 / 揭示三段，已抽中武器可横向滑动逐张查看
- 老虎机：基础 3 轴，可花金币追加到 6 轴（第 4~6 轴为倍率轴 ×5 ~ ×10000）；赌注支持输入数字、加倍跟注，转子左起逐个减速停下后才派彩，金币滚动结算
- **AWM 对玩家一枪 100**；每把武器有**自己的 PvP 伤害倍率**（不再用通用分类模板），`damage_vs_player` 仍是最高权威值
- AWM 有扇形子弹散布与长按蓄力收束，轨道炮 3 秒累计 240 伤（帧率无关），AWM / 轨道炮破空为白色线段而非拖曳
- 手雷、燃烧弹、烟雾弹已移出武器列表，作为投掷道具处理

## 僵尸与 Boss

32 种敌人由 **10 套统一行为模板**驱动，另有战术 AI（多玩家目标选择、群体分离、包围扇区、弹幕规避、Boss 血量阶段）。

- 近战攻击有**前摇 / 命中 / 后摇**，前摇期间定在原地并显示预警扇形，可走位抓 Timing 躲开；攻击间隔与范围按类型区分，写进数据库
- 冰霜僵尸投掷冷罐，落点生成淡蓝色圆形持续冰冻区域，施加冰冻 debuff
- Boss 免控（钩爪只能造成僵直），图鉴内所有条目均有程序化贴图

## 伤害、抗性与状态

- 伤害分基础伤害与倍率，走物理 / 燃烧 / 冰冻 / 中毒等 8 条抗性通道；魔法伤害为固定值并对 Boss 限幅
- 流血 / 燃烧 / 冰冻 / 中毒 / 眩晕 / 感电统一由 `EntityStatus` 管理，支持层数、时长、每跳伤害、易伤与渲染
- **debuff 免疫**：吃到 debuff 先叠层 → 满层后改为覆盖刷新 → 反复覆盖达到阈值后进入一段时间免疫；免疫**不清除当前已有的 debuff**，它按剩余时间自然走完，到期后计数归零
- **抗性计算系数按来源独立**：防爆肘击 0.25 / 载具撞击 0.20 / 技能 AOE 0.45，默认吃完整抗性；盾与载具耐久同步下调 40%
- **湮灭射线锁血制**：220/s 持续帧伤、总上限 480，对敌方玩家永不致死（精确保留 1 HP），对僵尸 / Boss 按 0.55 系数另算
- 主动格挡：独立摇杆，短按快速格挡、长按拖动改方向并蓄力；分普通 / 完美格挡，格挡期间无法攻击，挡完一次按受到的伤害进入冷却
- 近战武器为有节奏的多段连斩 + 月牙剑气，画质档位与光照可切换

## 多人

- 同屏双人：地图 → P1 武器 → P1 角色 → P2 武器 → P2 角色 → 开始，各自独立选择
- AI 玩家（`AIPlayer`）：最多 9 个，可设为友方 / 敌方、4 个阵营、五档难度（含「超难」透视 / 精确提前量 / 强锁）、武器 / 角色 / 策略偏好；会放技能、升级、救援队友、攻击玩家
- 视口数严格等于人类玩家数（1 人全屏、2 人分屏），AI 不额外占视口；玩家死后同阵营仍有 AI 则游戏继续
- 防爆肘击、载具撞击、狙击武器对敌方玩家各自有独立伤害倍率；技能手雷 / 空袭 / EMP 也能打到敌方玩家
- 僵尸能跨越障碍物，但穿越时移速降到 35%；技能预瞄线跟随当帧摄像机，拉远视野按「完整看到范围圈」计算

> **网络联机代码已在 v2.9.22 完全移除**（v2.9.23 继续保持），等待重新设计后再实现。回放、图鉴、独立地图编辑器等本地功能不受影响。

## 其他系统

- 技能：52 个词条，升级三选一，技能树 / 技能轮盘，主动技能上限 5 级；技能手雷飞行 1.1s → 0.32s
- **独立地图编辑器**：`python3 tools/map_editor_standalone.py`，键控 + 触控，导出 `.zmap`；「导出为当前地图」后游戏零配置加载 `maps/active.zmap`，障碍物 / 效果区 / 出生点全部应用。游戏内不再内置编辑器
- 视野机制：48 射线可见多边形 + 1/3 分辨率遮罩、每 3 帧重算；`VISION_PERF.md` 有「完全使用」的实测开销与结论（密集障碍下超一帧预算，不建议全量启用）
- 回放：死亡与通关录像均可保存，主菜单回放列表查看；帧快照含子弹、弹道、区域圈、粒子与技能光环
- 图鉴 / 剧情资料库 / 成就 50+ / 加密存档 / Mod 钩子系统 / 动态音乐 / 体力疾跑 / 屏幕震动 / 伤害数字合并跳动
- 自动更新：从 GitHub Release 拉取**唯一全量包**（增量更新已移除），失败自动回滚

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

Android 用 Pydroid3 或 Termux 运行，自动切换触控模式。依赖已固化在项目 `_vendor/` 目录，不会因环境重置而丢失。

## 控制

**键控**：WASD/方向键移动、鼠标瞄准、左键射击、Ctrl 疾跑、E 防爆套装、Q 肘击、F 钩爪、G 技能、1/2/3 切武器、R 下一把、T 技能树、ESC 暂停、F5 地图编辑器。

**触控**：左摇杆移动、右半屏瞄准、射击 / 技能 / 释放 / 疾跑 / 格挡摇杆、II 暂停；HUD 编辑页可用滑动条调整按钮尺寸与透明度。
